# Landing Page Biro Kemahasiswaan dan AIK - Universitas Siber Muhammadiyah

Landing page web modern yang interaktif dan responsif, dikembangkan untuk **Lomba Kreativitas Digital Universitas Siber Muhammadiyah (SiberMu)**. Halaman ini menyatukan informasi penting dari **Biro Kemahasiswaan** dan **Biro Al-Islam & Kemuhammadiyahan (AIK)** ke dalam satu antarmuka yang bersih, elegan, dan profesional.

---

## 🚀 Fitur Utama

- **Desain Responsif:** Dioptimalkan untuk berbagai perangkat mulai dari layar komputer/desktop, tablet, hingga ponsel pintar (_Mobile-First approach_ menggunakan CSS Grid & Flexbox).
- **Dark / Light Mode:** Pengguna dapat beralih antara mode terang dan gelap dengan satu klik tombol di navbar.
- **Multibahasa (ID / EN):** Mendukung terjemahan otomatis bahasa Indonesia dan bahasa Inggris secara instan tanpa memuat ulang halaman.
- **Navigasi Lengkap & Sticky Navbar:** Menu navigasi selalu berada di atas layar (_sticky_) untuk memudahkan akses lompat bagian (_smooth scrolling_).
- **Informasi Resmi & Media Sosial:** Menyediakan alamat lengkap Kampus Pusat SiberMu serta tautan langsung ke seluruh saluran media sosial resmi institusi.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** (Struktur semantik web)
- **CSS3** (Variabel CSS, Grid & Flexbox, Media Queries untuk responsivitas)
- **JavaScript (ES6+)** (Logika interaktif _smooth scroll_, _toggle_ tema gelap/terang, dan sistem terjemahan dinamis)
- **FontAwesome & Google Fonts (Inter)** (Ikon dan tipografi standar industri)
